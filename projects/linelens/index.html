PERSONAL PROJECT · SPORTS ANALYTICS

LineLens

A market-intelligence application that turns MLB sportsbook odds into clear, comparable prices.

  • Python
  • Streamlit
  • REST APIs
  • Supabase
  • pandas

The Idea

I wanted to focus on strong prices instead of guessing game outcomes. Sportsbook markets already reflect substantial research; LineLens compares the same pick across books and highlights prices that look favorable relative to the broader market.

What I Built

A Python and Streamlit application that retrieves and normalizes odds, calculates no-vig consensus, ranks market-relative prices, and tracks a paper portfolio. A separate demo mode makes the application explorable without API credentials.

Pipeline

  1. 01Retrieve & normalize

    Convert API responses into sportsbook-level rows.

  2. 02Match exactly

    Group by game, market, side, and line.

  3. 03Remove the margin

    Convert odds to probability and normalize each book.

  4. 04Find consensus

    Average qualifying no-vig probabilities.

  5. 05Rank prices

    Compare each price’s break-even probability with no-vig market consensus. A favorable price is an opportunity to inspect, not a prediction of a win.
