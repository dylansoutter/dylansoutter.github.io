Overview

GitTogether is a student project-discovery and collaboration platform built by a seven-person Georgia Tech WebDev team. The product brings together project listings, accounts, profiles, and opportunities to collaborate.

The repository remains a fork of the team project so its history and shared ownership stay visible.

My Role

My verified backend contributions are the registration/login controller and Mongoose Project model. Authentication covers input and duplicate-account checks, bcrypt password hashing, and JWT issuance.

Teammates contributed profile GET/PATCH APIs, project controllers, owner authorization, and frontend screens.

Architecture

  1. 01React frontend

    Project discovery and account screens.

Main Backend Contributions

AUTHENTICATION

  1. Registration or login request
  2. Validate input and account details
  3. Hash or verify password with bcrypt
  4. Issue a signed JWT

DATA MODELING

  • Title and description
  • Tech stack and needed roles
  • Creator reference to a User
  • College, open status, and timestamps

In the team’s authorization flow, protected routes verify the token and project edit/delete operations check the creator. Those authorization checks and the profile endpoints are team contributions.
